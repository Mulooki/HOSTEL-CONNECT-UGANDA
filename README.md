HostelConnect Uganda

A simple website that helps university students in Uganda find and compare student hostels in one place, instead of searching through WhatsApp groups and noticeboards.

Built as a beginner project using only HTML and CSS. There is no JavaScript, no framework and no database.

Features
- Home page with a welcome section, "How it works" steps and featured hostels
- Hostels page with cards for all 7 hostels and a quick price comparison table
- A details page for each hostel with its price, facilities, rules and caretaker phone numbers
- About page and Contact page with a message form
- Fits both computers and phones, using CSS Flexbox

Project structure
- `index.html`, `hostels.html`, `about.html`, `contact.html`: the main pages
- One `.html` page for each hostel, such as `royal-hostel.html`
- `css/style.css`: the single stylesheet used by every page
- `images/`: the logo and hostel photos

How to run
Download or clone the repository and open `index.html` in any web browser. No installation is needed.

Technologies
- HTML5
- CSS3 (Flexbox)

Note
Hostel information is for guidance only and may change. Always confirm prices and availability with the hostel.
